# Hobby Log

A personal hobby tracker. Log what you did each day, track progress per hobby, and keep a "want to" list under each hobby.

- Single static file: `index.html` (no build step)
- Data is stored in the browser (localStorage). Use Hobbies > Export backup to save a copy.
- Deploy: import this repo in Vercel, framework preset "Other", no build command.
- On iPhone: open the Vercel URL in Safari > Share > Add to Home Screen.
